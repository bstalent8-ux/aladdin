# Showroom authentication brand assets

The original four authentication references and their supplied README remain unchanged in docs/design/references/showroom-auth/.

The product owner supplied brand-colors-2026.jpg and brand-rebrand-2026.jpg during UI review. These originals are preserved in the same references directory.

aladdin-logo-2026.png is a transparent raster rendition derived from the approved navy-on-cream logo reference using ImageGen. It is not an original vector master. The showroom-interior-2026.png and showroom-interior-mobile-2026.png photographs are ImageGen edits replacing the obsolete wall branding with the new genie/ALADDIN lockup. The earlier extracted photographs are retained as source assets; the authentication pages use only the 2026 versions.

This update is scoped to the Showroom authentication pages. Shared brand assets and the original project checkout have not been replaced.

The pages load WebP copies of the two photographs (`showroom-interior-2026.webp`, `showroom-interior-mobile-2026.webp`, quality 82, about 160-180 KB instead of 2.2 MB) through the Next.js image optimizer; the PNGs stay as the source assets.
