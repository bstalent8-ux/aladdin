# Country flag artwork

Vendored 4:3 SVG assets from https://github.com/lipis/flag-icons at commit 086f7e97d657358203916dbe84f61c2bccaa81eb.
MIT license; see LICENSE. No runtime package or network dependency.
Country flags are data artwork, separate from the application icon system.
Used by the existing CountryPicker because Windows does not render regional-indicator emoji as flag images.
